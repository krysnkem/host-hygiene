Reclaim your Mac. Only when you say so.

host hygiene finds what is eating your disk, memory and CPU, explains each item in plain words, and clears only what you tick. It never closes an app for you.

$ brew install krysnkem/tap/host-hygiene

macOS only. Built for developers' machines, where build folders, SDKs and emulators fill the disk. Free and open source (MIT).

Three things it keeps an eye on

Each one works the same way: look, understand, then decide.

Storage

Gets space back, safely

Every item is explained with the exact command, what it frees and what it costs to get back. Dry run is the default.

  • my-app/build4.2 GB
  • Xcode DerivedData2.6 GB

Memory

Shows who is using it

Apps ranked by impact. A browser's thirty helper processes count as one row. You get directions for freeing memory; you do the closing.

CPU

Finds what keeps it busy

The five-minute load against the limit you set, and the apps behind it. System items are listed but never advised to be closed.

It never closes, kills or signals anything.

That is a rule the test suite enforces, not a hope. If a kill, a quit or a clipboard call appears in any script, the build fails.

safe-regenerableask-firstnever

Every item carries one of three classes. Only the first can be ticked by default.

dry run
Nothing is removed unless you pass --run or confirm in the interface.
re-checked
Each path must be absolute, with no .., no symlink, not your home folder, not a tracked file.
never-touch list
Name a folder once and it is refused everywhere, in every look.
alarms read only
They measure and notify. They clean nothing and close nothing.
no daemon
Alarms run as a launchd job, about 0.17 seconds a check. Nothing stays resident.

A tap on the shoulder, not a siren

Turn alarms on and host hygiene checks disk, memory and CPU against lines you set. It tells you once per crossing, respects quiet hours, and a click lands on the right screen: Storage for disk, Memory or CPU for the others. Snooze any alarm for an hour, a day, or until tomorrow.

Install in a minute

Needs macOS. The prebuilt interface runs on Apple Silicon; on Intel you get the plain shell menu, or build the interface once with a Dart SDK.

brewbrew install krysnkem/tap/host-hygiene
thenhh

Without Homebrew: download the archive from the latest release, unpack it and run ./install.sh. Remove it with ./uninstall.sh or brew uninstall host-hygiene; your settings in ~/.config/host-hygiene stay unless you delete them. Turned on alarms? Run hh schedule off first.
