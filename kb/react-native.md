## Entries

### rn-node-modules
- what: per-project `node_modules/` of a React Native or Expo app (JS dependencies, native module sources)
- catalog-id: none
- paths: <project>/node_modules
- size: commonly several hundred MB per project (unverified)
- class: safe-regenerable
- removal: rm-verified after git confirms it is ignored (then `npm install` / `yarn` / `pnpm install`)
- regen: reinstall from lockfile; needs network unless the package-manager cache is warm; native builds then re-link
- growth: per project; duplicated across projects unless pnpm's store is used
- source: (unverified)

### metro-cache
- what: Metro bundler transform cache (file-based, under the OS temp dir by default)
- catalog-id: none
- paths: $TMPDIR/metro-* , $TMPDIR/haste-map-* (macOS: /var/folders/*/T/)
- size: (unverified); nothing under /tmp matched on this host (measured here, but macOS uses $TMPDIR not /tmp)
- class: safe-regenerable
- removal: `npx react-native start --reset-cache` (or `npx expo start -c`) rebuilds it; deleting the temp dirs is rm-verified
- regen: first bundle after clearing is slower (minutes on large apps); no network
- growth: one cache per project/config hash; the OS clears the temp dir eventually. Suggested: clear only when the bundler misbehaves (suggested)
- source: reported online, https://metrobundler.dev/docs/caching/ (fetched 2026-11-17); confirms a `metro-cache` dir under the OS temp dir. `--reset-cache`/`start -c` and `haste-map-*` NOT confirmed; sizes (unverified)

## Developer habits
- Keeps many JS projects, each with a full `node_modules`, a `Pods` tree and an Android Gradle build.
- Runs the same project through Metro, Xcode and Gradle, so one app leaves three kinds of build output.
- Rebuilds after `pod install` or a dependency change, which recompiles all native code.
- Shares the heavy parts (CocoaPods cache, Gradle wrapper dists, Android SDK) with the iOS-native and Android-native types; see those files.

## Signals
- `package.json` with `react-native` or `expo` dependency; `metro.config.js`, `app.json`/`app.config.js`, `eas.json`
- `ios/Podfile`, `android/build.gradle` inside a JS project
- commands: `npx react-native`, `npx expo`, `eas`, `watchman`, `pod`, `yarn`, `pnpm`
- profile toolchain ids: node, android, gradle, xcode
